Módulo 1 — Registro de productos
HU-01 Registrar un nuevo producto en el inventario Alta
Como farmacéutico, quiero registrar un nuevo producto con nombre, descripción, precio, cantidad y audiencia, para que esté disponible en el inventario de la farmacia.
Criterios de aceptación
El formulario debe tener los campos: nombre, descripción, precio, cantidad y audiencia (adultos/niños).
Todos los campos son obligatorios; el sistema muestra un mensaje de error si alguno está vacío.
El precio y la cantidad no pueden ser valores negativos.
Al guardar exitosamente, el producto aparece de inmediato en el inventario.
Se muestra una notificación de confirmación tras el registro exitoso.
HU-02 Indicar si el producto es para adultos o niños Alta
Como farmacéutico, quiero clasificar cada producto como "adultos" o "niños" al registrarlo, para que el sistema aplique las reglas de descuento correctas.
Criterios de aceptación
El campo audiencia es un selector con exactamente dos opciones: Adultos y Niños.
Al seleccionar "Niños", se muestra un aviso informativo indicando que se aplicará un 5% de descuento adicional.
La audiencia queda almacenada y visible en la tarjeta del producto en el inventario.
HU-03 Limpiar el formulario de registro Baja
Como farmacéutico, quiero poder limpiar todos los campos del formulario con un botón, para que pueda comenzar un nuevo registro sin borrar manualmente cada campo.
Criterios de aceptación
El botón "Limpiar" vacía todos los campos del formulario.
El aviso de descuento para niños desaparece al limpiar el formulario.
No se elimina ningún producto ya registrado.
Módulo 2 — Visualización de stock
HU-04 Ver todos los productos disponibles en inventario Alta
Como farmacéutico, quiero ver todos los productos registrados en una cuadrícula de tarjetas, para que pueda conocer el inventario completo de un vistazo.
Criterios de aceptación
Cada tarjeta muestra: nombre, descripción, precio, cantidad disponible y audiencia.
El indicador de stock cambia de color: verde (suficiente), naranja (bajo stock <10), rojo (sin stock).
Los productos recién registrados aparecen en el listado sin necesidad de recargar la página.
HU-05 Filtrar productos por audiencia Media
Como farmacéutico, quiero filtrar el inventario por "Todos", "Adultos" o "Niños", para que pueda encontrar productos de una categoría específica rápidamente.
Criterios de aceptación
Existen tres botones de filtro: Todos, Adultos y Niños.
Al hacer clic en un filtro, solo se muestran los productos de esa audiencia.
El filtro activo se resalta visualmente para indicar la selección actual.
Si no hay productos en esa categoría, se muestra un mensaje informativo.
HU-06 Buscar productos por nombre o descripción Media
Como farmacéutico, quiero buscar productos escribiendo en un campo de texto, para que pueda localizar un producto específico sin recorrer todo el inventario.
Criterios de aceptación
El buscador filtra en tiempo real mientras el usuario escribe.
La búsqueda aplica sobre el nombre y la descripción del producto.
La búsqueda es compatible con el filtro de audiencia activo.
Si no hay coincidencias, se muestra el mensaje "No se encontraron productos".
Módulo 3 — Precios y descuentos
HU-07 Aplicar descuento del 20% a productos Alta
Como cliente, quiero ver el precio con descuento aplicado automáticamente en todos los productos, para que pueda conocer el valor real que pagaré.
Criterios de aceptación
Los productos muestran el precio final con el 20% de descuento aplicado.
El precio original se muestra tachado junto al precio con descuento.
Se muestra un badge "-20%" visible en la tarjeta del producto.
El descuento se calcula automáticamente sin intervención del usuario.
Módulo 4 — Carrito de compras
HU-08 Agregar un producto al carrito Alta
Como cliente, quiero agregar productos al carrito desde el inventario, para que pueda seleccionar los medicamentos que deseo comprar.
Criterios de aceptación
Cada tarjeta de producto tiene un botón "Agregar al carrito".
Al agregar, el contador del carrito en la barra superior se incrementa y muestra una animación.
Si el producto ya está en el carrito, se incrementa su cantidad en lugar de duplicarlo.
Se muestra una notificación confirmando que el producto fue agregado.
El botón está deshabilitado si el producto no tiene stock disponible.
HU-09 Modificar la cantidad de un producto en el carrito Alta
Como cliente, quiero aumentar o disminuir la cantidad de cada producto en el carrito, para que pueda ajustar mi pedido sin tener que eliminarlo y volver a agregarlo.
Criterios de aceptación
Cada ítem del carrito tiene botones "+" y "−" para modificar la cantidad.
No se puede superar la cantidad disponible en stock.
Si la cantidad llega a 0, el producto se elimina automáticamente del carrito.
El precio total del ítem se recalcula en tiempo real al cambiar la cantidad.
HU-10 Eliminar un producto del carrito Media
Como cliente, quiero eliminar un producto del carrito, para que pueda quitar ítems que ya no deseo comprar.
Criterios de aceptación
Cada ítem del carrito tiene un botón de eliminar (icono de papelera).
Al eliminar, el ítem desaparece del carrito y los totales se recalculan.
Si el carrito queda vacío, se muestra el mensaje "El carrito está vacío".
HU-11 Ver el resumen de costos en el carrito Alta
Como cliente, quiero ver el subtotal, el descuento aplicado y el total final en el carrito, para que pueda saber cuánto pagaré antes de finalizar la compra.
Criterios de aceptación
El carrito muestra: subtotal (sin descuento), descuento total y total final.
Los valores se actualizan automáticamente al agregar, eliminar o cambiar cantidades.
El descuento se muestra por separado y en color diferenciado.
HU-12 Finalizar la compra Media
Como cliente, quiero finalizar mi compra con un botón de confirmación, para que se registre el pedido y se limpie el carrito.
Criterios de aceptación
El botón "Finalizar compra" está visible en la parte inferior del carrito.
Al confirmar, el carrito se vacía y se cierra el panel.
Se muestra una notificación de compra exitosa.
